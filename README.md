# 📚 Exercícios e Estudos de Python

Este repositório reúne meus códigos de estudo, atividades de cursos e pequenos projetos desenvolvidos para consolidar meu aprendizado na linguagem Python. A estrutura está organizada por conceitos e bibliotecas para facilitar a navegação e a revisão dos fundamentos.

---

## 📁 Estrutura de Pastas

### 1. `logica_e_basico/`
Contém exercícios práticos voltados ao aprendizado inicial de lógica de programação em Python:
* Estruturas condicionais e de repetição.
* Manipulação de variáveis e listas.
* Criação de funções básicas.
* Armazenamento inicial de dados (ex: scripts de tarefas).

### 2. `POO/` (Programação Orientada a Objetos)
Códigos desenvolvidos para praticar os conceitos da POO em Python:
* Criação e modelagem de classes (atributos e métodos).
* Instanciação de objetos.
* Encapsulamento, herança e polimorfismo na prática.

### 3. `interfaces_graficas_tkinter/`
Implementações de telas e janelas gráficas utilizando a biblioteca desktop padrão do Python, **Tkinter**:
* Gerenciamento de janelas, layouts, frames e botões.
* Validações de entradas do usuário.
* Interface gráfica conectada a scripts funcionais.

### 4. `banco_de_dados_sqlite/`
Estudos práticos sobre a integração do Python com bancos de dados relacionais leves:
* Conexão e criação de tabelas usando **SQLite3**.
* Operações básicas de CRUD (Inserção, Leitura, Atualização e Deleção de dados).
* Modelagem simples de dados para sistemas escolares ou de cinema.

---

## 🚀 Como Executar os Códigos
Qualquer um dos arquivos `.py` pode ser executado diretamente pelo terminal caso você possua o Python instalado:
```bash
python nome_do_arquivo.py
```
*(Para os scripts da pasta de interfaces gráficas, certifique-se de que o Python instalado no seu sistema possui suporte a Tkinter).*
